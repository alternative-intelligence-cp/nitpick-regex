## 4. What will bite

- **`apply.py` stages what it applies.** Commit after each block, and nothing else: `git -C "$REPO" status
  --short` before the commit shows the step's files and no others. A STOP writes nothing — read the message, find
  the drift, and amend the patch.
- **A re-run on a later day STOPs** where it would say ALREADY: the dates `@@DATE@@` became differ. That is the
  safe answer; compare the tree with `HEAD` by hand before doing anything else.
- **Probe 18's position is a measurement**, 35:39 in the moved file; the literal's is 31:22. A worker who edits
  either header by a line moves it, and the harness says so.
- **`#[derive(Copy)]` on a struct needs every member `Copy`** — `AstKind` too. A struct that later gains an
  owning member is refused at its declaration.
- **The manifest's layout is the FULL string.** `llvm-as` completes a partial one, which then fails the belt;
  copy it from the patch, never retype it.
- **A self-check case tree carries the pins too** (`selfcheck.py`'s `TOML`): a case tree without them fails
  before it reaches the thing it tests, which is a red for the wrong reason.
- **A reserved word is refused as a binding name** — `end`, `in`, `range`, `any`, `unit`, `stack` … — and a
  field name is its own namespace (RX-134).
- **`grep` here is ugrep**: over several files it prints in completion order; every count this plan asserts
  comes from one file, `git grep`, or a sorted list.
- **The emission assertion runs on GitHub's runner**, not here — the local rehearsal checked its syntax and its
  numbers, not its verdict. Step 8 reads it.
- **earlyoom.** A step that dies by 143 or 137 is read against its journal first.
