## 6. What will bite

- **A computed tree is finished**: `hir_set` and `hir_set_root` stop on it (`hir_props_frozen_set`,
  `hir_props_frozen_root`). Compute the facts last — `hir_build`, `hir_read` and `hir_normalise` write before any query
  and never after.
- **The query writes**: `hir_props` takes `Hir->:h`, since it may run the pass. A reader holding a `Hir` by value cannot
  ask it.
- **`hir_props` stops on a node the root does not reach**, and on a `Hir` with no root: it never answers no bits for no
  facts (`hir_props_not_in_tree`, `hir_props_no_root`).
- **A node copied from a computed tree carries none of its facts**: `hir_push` and `hir_set` drop them, so the normal form
  of a computed tree computes its own (`hir_props` case 20).
- **A `decreases` measure calls only a `pure` function** (§1.3): a loop over the arena measures by a local.
- **A comment's account of the code beside it is a claim** (0.2.3's record, *"To the planner of 0.2.4"*): read each
  comment the patches add against its code before applying the patch. Three of the first cut's drafts said more than
  their code did, one quoted half of what it dated, and the first cut's account of its mutants claimed more than its table
  held (§8, items 2 and 5); §1.12 counts their replaced words in the patches.
- **A full run took four to four and a half minutes here, and block 2m four and a quarter**: each is its own block, one at a
  time on the machine, under the harness lock.
- **`apply.py` stages what it applies; commit after each step's last block and nothing else. It dates the run once**, in
  `.internal/w024/date`: leave the file for the whole run, and a re-run under it says `ALREADY`.
- **A check reads its OWN tree**: `tchecks` asks each tree's own harness, `facts.sh` each copy's. **`git apply` inside this
  checkout resolves a patch's paths against the checkout**: `facts.sh` applies with GNU `patch -d`, `apply.py` with
