### 6.1 A compiler defect: an impl may declare `move` on a parameter its trait lends

**Raise by path** — this section is the path, and `tests/probe/probe18_impl_adds_move.npk`
the committed form once step 3 lands it; the orchestrator numbers it. Reproduction, no
library code, at `c970483` and `c3bdae2`, −O0 and `opt -O2`:

```text
trait:Dup = { func:dup = Self(Self:self) never fails; };
impl:string:Dup = { func:dup = string(move string:self) never fails { pass self; }; };   -- accepted
func:twice<T: Dup> = T(T:x) never fails { pass raw x.dup(); };
run:  string:a = string_concat("abbb…b", "c");  string:b = raw twice::<string>(a);
      -> both `a` and `b` dropped at run's end: 95 (Unreachable, a double free)
the same through a concrete call, `raw a.dup()`:                               95
the same through a PRELUDE trait, `impl:Named:Eq` with `move Named:self`:        95
the reverse, a trait's `move Self:self` implemented lent `string:self`:           compiles, runs 46
controls: the impl written as declared, `string(string:self)`                  NITPICK-TYPE-047
          a plain function with a `move` parameter called without `move(...)`  NITPICK-TYPE-046
```

**The rule it breaks:** `TRAITS_REFERENCE.md` §2, *"An impl's method must have the
signature the trait declares — including the contract"*; the checker enforces the
`never fails` half (`TYPE-041`) and not a parameter's ownership. **Where:** the comparison
is `same_signature` in the compiler's `src/frontend/type_trait.npk` (read at `c970483`),
which compares the return and each parameter's TYPE through `same_after_self` and never
reads a parameter's `move`; when it answers false the impl is refused `NITPICK-TYPE-014`,
*"does not have the signature … declares"*. **Requested:** compare each parameter's `move`
qualifier with the trait's there, and refuse a difference in either direction, under that
code. **What it blocks (W-27):** nothing in `src/`; it weakens `vec_get`'s `T: Pod`
for a consumer who writes a `move`-self impl (95 through `vec_get`, measured), and it gates
the type-level bound (the O-R entry). **Not a regression**: 95 at `c3bdae2` too. Every
trait with a by-value parameter is exposed, the prelude's seven included, so its extent is
ecosystem-wide — **every library with an impl should be swept** once the compiler answers.

### 6.2 For the compiler seat: a design input — a generic container has no infallible by-value read

body, and the prelude declares `func:clone = Self(Self:self);` MAY FAIL (the `string` impl

container's element is not a place outside its module. This library answers with its own
`Pod` (PD-12); a prelude `Copy`-like marker, or a `never fails` clone for the types that
cannot fail, would retire it. **Blocks nothing**; offered as input, not as a request to wait
