## Why `0.0.4b`, decided at planning

**The adoption is its own subcycle, numbered `0.0.4b`: inserted after 0.0.4 and
before the close, moving no existing number.**

- **The letter is the compiler's convention for an inserted subcycle** — its
  1.5.1b sat between 1.5.1 and 1.5.2, and 1.5.8b, c and d followed 1.5.8 — and
  `nitpick-time` used it the same day for the same purpose (`0.1.0b`). It sorts
  between `0.0.4` and `0.0.5` in the cycle README's table, which is what the
  orchestrator's picker reads (the first subcycle not `DONE`).
- **It must precede the close, not follow it.** The close is judged by an audit
  that has seen the tree it accepts ([`README.md`](README.md)'s Gate), and a
  tree that does not compile at the pin cannot be judged at all.
- *Declined — `0.0.6`:* it would be the cycle's last subcycle, so the worker's
  close rule (`skills/worker/SKILL.md` §7) would have it report
  `READY-TO-CLOSE` and trigger an audit of an adoption; and its number would put
  it after the close it must precede.
- *Declined — renumbering the close to `0.0.6`:* every citation of 0.0.5 — its
  §8 and §9 triages, RX-140's archive reversal, three audits, the board, the
  record — would silently point at the wrong work, and `ROADMAP.md`'s numbering
  rule refuses exactly that.
- *Declined — folding the adoption into the close's re-attempt:* the close is a
  triage of three audits, and a seventy-file mechanical diff inside it can be
  reviewed as neither; and the triage has to read the adopted tree, which must
  exist first. The board's question 6 also answered that the CI pin bump is
  its own commit.
- *Declined — cycle 0.1:* 0.1 is gated on 0.0 (`../ROADMAP.md`'s table), and
  0.0 is not closed.

**`0.0.4c` follows the same rule, and the board's item 13 is placed there**
rather than here ([`0.0.4c.md`](0.0.4c.md) says why: this is mechanical, that
is design).

```bash
sweep() {   # $1 = label [$2 = npkc]; writes $A/$1.log, prints the tally
  local cc=${2:-$NPKC}; : > "$A/$1.log"
  for f in $( { git -C "$REPO" ls-files '*.npk'; git -C "$REPO" ls-files --others --exclude-standard '*.npk'; } | sort -u ); do
    out=$(cd "$REPO/$(dirname "$f")" && "$cc" "$(basename "$f")" -o /dev/null 2>&1); st=$?
    printf '=== %s (exit %s)\n%s\n' "$f" "$st" "$out" >> "$A/$1.log"
  done
  echo "files $(grep -c '^=== ' "$A/$1.log")  exit-0 $(grep -c '^=== .*(exit 0)' "$A/$1.log")"
  grep -oE '^NITPICK-[A-Z]+-[0-9]+' "$A/$1.log" | sort | uniq -c
}
sweep before_old "$OLD/npkc"     # expect: files 79 exit-0 71; BORROW-009 1, PICK-003 1, REACH-002 2, RUNG-001 3, TYPE-004 1
```

```python
#!/usr/bin/env python3
# arm_sweep.py LOG REPO -- insert §2's arms where NITPICK-REACH-002 names them.
import re, sys, collections
CODES = {"StackExhausted": 106, "MachineFault": 107, "DecreasesViolated": 108,
         "ShiftRange": 115}
ORDER = ["StackExhausted", "MachineFault", "DecreasesViolated", "ShiftRange"]
# THE DELIBERATE REFUSALS AND THE ONE IDENTITY EACH IS ABOUT. A file is NEVER
# given its own subject -- that would make it compile and assert nothing -- but
# it IS given every other arm REACH asks, so that its only REACH-002 line is its

# wrong identity: exactly how probe13a was masked at this pin.
SUBJECT = {
    "tests/probe/refused/probe13c_requires_refused.npk":  "RequiresViolated",
    "tests/probe/refused/probe13d_ensures_refused.npk":   "EnsuresViolated",
    "tests/probe/refused/probe13f_limit_arm_missing.npk": "LimitViolated",
    "tests/rejection/failsafe_missing_system_arm.npk":    "WildLeak",
}
log, repo = sys.argv[1], sys.argv[2]
want, other, cur = collections.defaultdict(set), collections.defaultdict(set), None
for ln in open(log):
    m = re.match(r"^=== (\S+) \(exit", ln)
    if m: cur = m.group(1); continue
    m = re.match(r"^NITPICK-REACH-002 \S+ `failsafe` does not name `([^`]+)`", ln)
    if m and cur:
        x = m.group(1)
        (want if x in CODES and SUBJECT.get(cur) != x else other)[cur].add(x)
nowild = []
for f, ids in sorted(want.items()):
    lines = open(repo + "/" + f, encoding="latin-1").read().split("\n")
    fs = next(i for i, l in enumerate(lines) if re.match(r"^\s*func:failsafe\b", l))
    # THE ARM, NOT A MENTION: `(*)` in the code part of the line, before any `//`.
    star = next((i for i in range(fs, len(lines)) if "(*)" in lines[i].split("//")[0]), None)
    if star is None: nowild.append((f, sorted(ids))); continue
    ind = re.match(r"^(\s*)", lines[star]).group(1)
    pre, post = lines[star].split("(*)", 1)
    new = ["%s(%s) { exit %di32; }," % (ind, x, CODES[x]) for x in ORDER if x in ids]
    lines[star:star + 1] = ([pre.rstrip()] if pre.strip() else []) + new + [ind + "(*)" + post]
    open(repo + "/" + f, "w", encoding="latin-1").write("\n".join(lines))
done = {f: s for f, s in want.items() if f not in dict(nowild)}
print("edited", len(done), "roots")
for x in ORDER: print("  %-18s %d" % (x, sum(1 for s in done.values() if x in s)))
for f, ids in sorted(other.items()): print("LEFT ALONE", f, sorted(ids))
for f, ids in nowild: print("NO WILDCARD -- ARM BY HAND", f, ids)
```

### Step 5b — every `src/` loop runs under the tests

Plant, one loop at a time, a measure that traps on first entry —

```python
#!/usr/bin/env python3
# loopcov.py TREE NPKC NPKRT -- which unit programs enter each src/core loop.
import os, re, subprocess, sys, tempfile, shutil
tree, npkc, npkrt = sys.argv[1:4]
loops = []
for f in sorted(os.listdir(os.path.join(tree, "src/core"))):
    for n, l in enumerate(open(os.path.join(tree, "src/core", f), encoding="latin-1").read().split("\n"), 1):
        if re.search(r"^\s*while \(.*\) decreases ", l): loops.append(("src/core/" + f, n))
units = sorted("tests/unit/" + u for u in os.listdir(os.path.join(tree, "tests/unit")) if u.endswith(".npk"))
units.append("tests/conformance/import.npk")
tmp = tempfile.mkdtemp()
def run(u):
    ll, o, b = (os.path.join(tmp, x) for x in ("p.ll", "p.o", "p"))
    if subprocess.run([npkc, os.path.basename(u), "-o", ll], cwd=os.path.join(tree, os.path.dirname(u)),
                      capture_output=True).returncode: return "npkc"
    subprocess.run(["llc", "-O0", "-filetype=obj", "-relocation-model=static", ll, "-o", o], check=True)
    subprocess.run(["ld.lld", "-static", o, npkrt, "-o", b], check=True)
    try: return str(subprocess.run([b], timeout=60).returncode)
    except subprocess.TimeoutExpired: return "timeout"
for f, n in loops:
    p = os.path.join(tree, f); orig = open(p, encoding="latin-1").read(); lines = orig.split("\n")
    lines[n - 1] = re.sub(r"decreases .*? \{", "decreases 0i64 - 1i64 {", lines[n - 1], count=1)
    open(p, "w", encoding="latin-1").write("\n".join(lines))
    try: hits = [u for u in units if run(u) == "108"]
    finally: open(p, "w", encoding="latin-1").write(orig)
    print("%-22s %-4d caught by %d: %s" % (f, n, len(hits), ", ".join(os.path.basename(h) for h in hits)))
shutil.rmtree(tmp)
```
